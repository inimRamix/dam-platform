# Корпоративная DAM-система

Система управления цифровыми активами (Digital Asset Management) для централизованного хранения, поиска, версионирования и аналитики медиа-контента с возможностью автоматической сборки макетов.

## Возможности
- Загрузка и хранение медиафайлов (изображения, PDF)
- Автоматическое извлечение цветовой палитры, текста (OCR) и полнотекстовый поиск
- Версионность ассетов
- Ролевая модель доступа (администратор, дизайнер, менеджер)
- Приглашение пользователей по email с ограничением по доменам
- Аналитика использования (просмотры, скачивания) в реальном времени
- Генерация превью и динамическая трансформация изображений

## Технологический стек
- **Backend:** Python 3.12, FastAPI, PostgreSQL 16, Elasticsearch 8, Redis 7, RabbitMQ, MinIO, ClickHouse
- **Frontend:** React 19, TypeScript, Ant Design, TanStack Query, Zustand
- **Инфраструктура:** Docker, Docker Compose v2, GitHub Actions

## Как запустить проект:

1. Склонируйте репозиторий:
```
git clone https://github.com/inimRamix/dam-platform.git
```
2. Скопируйте `.env.example` в `.env` и задайте переменные
3. Выполните `docker compose up -d`
